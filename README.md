# Telegram Notifier Microservice

Этот микросервис на базе **NestJS** предназначен для отправки уведомлений в Telegram-каналы или чаты через Telegram Bot API. Он принимает HTTP POST-запросы с указанием идентификатора канала (`channelId`) и текста сообщения (`message`).

## Требования

*   Node.js (рекомендуется v18+)
*   pnpm (или npm/yarn)
*   Токен Telegram-бота (полученный от @BotFather)

## Установка

1.  **Клонируйте репозиторий (или создайте файлы):**
    \`\`\`bash
    # Если вы используете git
    git clone <URL_РЕПОЗИТОРИЯ>
    cd telegram-notifier-service
    # Если вы используете файлы, предоставленные Manus AI
    cd telegram-notifier-service
    \`\`\`

2.  **Установите зависимости:**
    \`\`\`bash
    pnpm install
    \`\`\`

3.  **Настройка переменных окружения:**
    Создайте файл `.env` в корне проекта и добавьте в него токен вашего Telegram-бота.

    **.env**
    \`\`\`
    # Токен вашего Telegram-бота
    TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_БОТА
    # Порт, на котором будет работать микросервис (по умолчанию 3000)
    PORT=3000
    \`\`\`

    **Важно:** Убедитесь, что ваш бот добавлен в целевой Telegram-канал или чат и имеет права на отправку сообщений. Для отправки в канал, бот должен быть администратором канала.

## Использование API

Микросервис предоставляет одну конечную точку для отправки уведомлений.

### Отправка уведомления

*   **Метод:** `POST`
*   **URL:** `/telegram/send-notification`
*   **Content-Type:** `application/json`

**Тело запроса (JSON):**

| Поле | Тип | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `channelId` | `string` | Идентификатор канала/чата. Может быть `@channelusername` или числовым ID (например, `-1001234567890`). | `"-1001234567890"` |
| `message` | `string` | Текст сообщения для отправки. Поддерживает форматирование **Markdown**. | `"Сервер *web-01*\\nСтатус: \\`DOWN\\`\\nВремя: 2025-11-02 10:00:00"` |

**Пример запроса (с использованием `curl`):**

\`\`\`bash
curl -X POST http://localhost:3000/telegram/send-notification \\
-H "Content-Type: application/json" \\
-d '{
    "channelId": "-1001234567890",
    "message": "Сервер *web-01*\\nСтатус: \\`DOWN\\`\\nВремя: 2025-11-02 10:00:00"
}'
\`\`\`

**Пример успешного ответа:**

\`\`\`json
{
    "statusCode": 200,
    "message": "Notification sent successfully"
}
\`\`\`

## Важные замечания по `channelId`

*   **Для публичных каналов:** Используйте `@channelusername`.
*   **Для приватных каналов и групп:** Необходимо использовать числовой идентификатор чата (Chat ID), который начинается с `-100`.
    *   **Как получить Chat ID приватного канала/группы:**
        1.  Добавьте своего бота в канал/группу как администратора.
        2.  Отправьте любое сообщение в канал/группу.
        3.  Используйте Telegram Bot API для получения обновлений (например, `https://api.telegram.org/botВАШ_ТОКЕН_БОТА/getUpdates`). В ответе найдите объект `chat` и поле `id`. Это и будет ваш `channelId`.
